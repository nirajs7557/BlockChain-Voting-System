# Blockchain Voting System

A secure, transparent, and tamper-proof voting system built on blockchain technology.

## Features

- Vote for candidates: Aman, Karan, Niraj, or Gopal
- Each vote is recorded as a block in the blockchain
- Real-time results tracking
- Immutable voting record
- Responsive design

## How to Use

1. Open index.html in a web browser
2. Select a candidate by clicking on their card
3. Click "Cast Vote" to record your vote
4. View the blockchain growing with each vote
5. Monitor real-time results

## Technology

- HTML5
- CSS3
- JavaScript
- Blockchain principles
